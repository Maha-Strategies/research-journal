# Deposit readiness: Zenodo / OSF

## Recommended first deposits

1. **The Volcanic Engine** — a bounded synthesis with a clear public-education connection and a stable current research-site edition.
2. **The Perturber Question Under Audit** — a methods/replication paper with a documented revision and an explicit computational boundary.
3. **The de Sitter Problem in the String Swampland** — a literature map whose provenance tags make its scope legible to an external reader.

These are recommended as **working papers**, not peer-reviewed articles. Before deposit, the author should make one final source and claim review, confirm that all third-party figures/materials may be redistributed, and decide the appropriate license.

## Deposit bundle for each paper

- Stable PDF from `public/papers/<slug>.pdf`
- `citation.bib` and `citation.cff` downloaded from the paper page
- `metadata.json` with status, version, and structured references
- Any reproducible code or data that may be shared lawfully
- A short `README` stating the paper's status, version, and known limitations

## Zenodo first, then OSF where useful

Use Zenodo for a versioned public record and DOI. Reserve the DOI before finalizing the PDF if it should appear in the document; Zenodo documents both DOI reservation and versioning. For an OSF preprint, connect an OSF project and submit the same final PDF only after all authors and rights holders approve it. OSF notes that a public preprint gets a persistent URL/DOI and can receive new versions.

Do not deposit a manuscript that is not ready for permanent public access. A Zenodo record and an OSF preprint are external, durable publications; repository status must never be represented as peer review.
